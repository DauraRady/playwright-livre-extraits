# Maîtriser JavaScript, TypeScript et Playwright — Extraits

Ce dépôt contient des extraits du livre *Maîtriser JavaScript, TypeScript et Playwright*, en cours de rédaction par **Daura Rady**. Sortie prévue en septembre 2026.

Le livre couvre l'architecture complète d'un framework de tests Playwright : arborescence de projet, Page Objects scopés composant, services API, stratégie de données de test, fixtures, configuration commentée et intégration CI/CD.

## À propos

Le contenu est issu de missions de conception et d'audit de frameworks Playwright en production. L'angle du livre n'est pas de reformuler la documentation officielle, mais de documenter ce qui casse en pratique, pourquoi, et comment le concevoir pour que ça ne casse pas.

Œuvre en cours de rédaction. Dépôt de l'œuvre effectué auprès de l'INPI (e-Soleau).
